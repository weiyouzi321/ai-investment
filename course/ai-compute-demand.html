核心理念

AI 算力是一个依赖链：你需要芯片来处理数据、内存带宽来供给芯片、能源来驱动数据中心、以及高速互连来连接一切。总的可用算力只能以其中最薄弱的环节的速度增长。

与此同时，由更大模型、更多用户和新应用驱动的算力需求正以惊人的速度增长。供给与需求之间的缺口告诉我们经济压力（和利润）集中在何处。

为什么这对AI经济至关重要

瓶颈决定了定价权。哪个环节最受限，哪个环节就能收取最高价格。这就是为什么 NVIDIA 一直拥有非凡的利润率——芯片曾是瓶颈。但随着芯片供应扩大，瓶颈可能转移到能源、互连或内存——随之而来的是价值创造的中心也会转移。

计算逻辑

计算器应用了一个简单但强大的原则：有效供给增长 = min(所有供给因素)。这是将 Liebig 最小因子定律应用于算力基础设施。

// 有效吞吐量增长
supply_growth = min(chips, memory, energy, network)

// 缺口告诉你系统有多受限
gap = supply_growth - demand_growth

// gap < 0 → 需求超过供给 → 价格上升
// gap > 0 → 供给超过需求 → 商品化
试试这些场景

场景1：NVIDIA 解决芯片供给。 将芯片产量推到 80%+。观察瓶颈转移到能源。这大致是 2025–2026 的轨迹——台积电扩大产能，但数据中心电力难以跟上。

场景2：需求放缓。 将需求拉到 100%/年。供给可能赶上，缺口关闭。这是"AI 寒冬" scenario——投资收益变得更难。

场景3：能源突破。 将能源推到 50%/年（核能复兴、模块化反应堆）。瓶颈转移到内存带宽——一些研究者认为这将是训练前沿模型的下一个壁垒。

场景4：所有因素均衡提升。 将所有供给因素设为 ~60%。系统没有单一堵点，各层竞争加剧，整个栈的利润率被压缩。
